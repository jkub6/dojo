# Security Policy

## Supported Versions

Only the latest release branch of Dojo currently receives security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of Dojo seriously. If you believe you have found a security vulnerability,
please report it privately.

**Do NOT open a public GitHub issue for security vulnerabilities.**

To report a vulnerability:

1. Email **jkub66@gmail.com** with the subject line:
   ```
   Dojo Security Vulnerability
   ```
2. Include the following details in your report:
   - **Description**: A summary of the vulnerability and its potential impact.
   - **Steps to Reproduce**: Detailed reproduction steps, sample configuration files, or a minimal
     proof of concept.
   - **Impact Assessment**: An explanation of what an attacker could achieve or compromise.
   - **Suggested Fix** *(optional)*: Any potential remediation or patches you have identified.

### Response Time

- You will receive an initial response acknowledging your report within **48 hours**.
- We will coordinate investigation, fix development, and release timing privately before any public
  disclosure.
